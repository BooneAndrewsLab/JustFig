# JustFig logo

Source: Claude Design project "JustFig identity" (2026-10-10), briefed from
`design/brief/`. The files here are the project's `export/` folder with the
C2PA provenance `<metadata>` block stripped from the SVGs to keep them small.
Sibling logos: `../../../PlasmidPop/design/logo`, `../../../BarelySig/design/logo`.

Mark: lowercase "j" in the PlasmidPop / BarelySig grammar. Stem 11 wide
(centre x 48.5, from y 17.5) running into the bowl's arc (r17, stroke 11,
centre 31.5,40) that turns left under the baseline and ends at 150°. The dot
is a legend swatch pair: two 8×8 squares at y 3, ink at x 32 and red at x 46,
the red one directly over the stem, top-right where the siblings' red devices
sit. It reads as a figure legend's key (one colour per condition). In the
lockup the mark stands in for the "j" of "justfig".

Files

- justfig-mark-light.svg: ink #201e1d + red #ec3013, 64×64, for light backgrounds
- justfig-mark-dark.svg: off-white #f3f2f2 + red, for dark backgrounds
- justfig-mark-on-red.svg: off-white + ink red-swatch (the left swatch stays
  off-white with the letter)
- justfig-favicon.svg: heavier cut for 16/32 px (stem/hook 14, arc r15,
  swatches 12×12 with a 5-unit gap so they stay apart at 16 px); transparent,
  ink switches with `prefers-color-scheme`, red swatch constant. The export
  referenced `.s`/`.f` classes without defining them; the `<style>` block was
  added here, as in BarelySig's favicon.
- justfig-app-icon.svg: 512 ink tile, no rounding, off-white + red mark at
  ~70 % of the tile height (scale .74)
- justfig-app-icon-maskable.svg: same at scale .64 so the red swatch's corner
  stays inside the 80 % safe circle
- justfig-lockup-light.html / -dark.html: mark + outlined wordmark,
  self-contained, no font load
- justfig-wordmark-paths.svg: outlined "ust" (`#ust`, ink) and "fig" (`#fig`,
  red) at 64 px type, baseline at y 0
- justfig-tool-icons.svg / .md: 16-unit line icons, ten tools + six chrome
  glyphs, stroke 1.4, round caps, `currentColor`

Wordmark

- Font: Archivo 700, width axis 88, letter-spacing -0.035em, lowercase;
  outlined from `Archivo[wdth,wght].ttf` (`../brief/references/fonts/`).
  "fi" is the font's default ligature.
- Text: "ust" in ink, "fig" in red
- Mark height = 1.24 × font size (79 px box at 64 px). The j's baseline is at
  y 50 of the 64-unit box: the mark's box bottom sits 0.27 em (17 px at 64)
  below the text baseline. Gap mark-to-text 3 px at 64 px.
- The j has a dot above and a hook below, so at the siblings' 1.32–1.44 × it
  overshoots the x-height far more than "p" or "b" and reads as a capital J;
  1.24 × keeps the stem top just above the x-height and the hook at the g's
  descender depth.
- At the 26 px top-bar lockup the type is 21.6 px.

Palette

- Ink #201e1d · Ground #f3f2f2 · Accent #ec3013

Where the logo is used in the app

- `public/favicon.svg`: justfig-favicon.svg, copied
- `public/icons/*.png`: PWA icons (192, 512, maskable 512), generated by
  `scripts/make-icons.sh` from the two app-icon SVGs
- `index.html`: the loading screen shows the light mark at 56 px
- `src/ui/Logo.tsx`: header lockup (mark + outlined wordmark, ink via
  `currentColor`); `src/ui/logoWordmark.ts` holds the paths from
  justfig-wordmark-paths.svg
- `src/ui/icons.tsx`: the tool and chrome icons from justfig-tool-icons.md
