# Citing JustFig

If JustFig helped you make a figure in a paper, a poster or a thesis, please say so. It helps other people find the tool, and it supports keeping it free.

## How to cite

The repository has a `CITATION.cff` file with the exact reference. On GitHub, the **Cite this repository** button on the project page reads it and gives you the citation in common formats. The tool has a DOI from Zenodo once a release is made; the DOI has not been minted yet, so see CITATION.cff for the DOI once released.

Until then, cite the web address of the app and the version number. The version is shown beside the title of this guide (open it with the **?** button), for example "Version 0.1.0". The project page is [github.com/BooneAndrewsLab/JustFig](https://github.com/BooneAndrewsLab/JustFig).

You can say it in your methods like this: "Figures were prepared with JustFig (version X)."

## Crediting icons

The icons in the library are the work of other people, shared under open licences. Most ask for a credit.

- JustFig writes the credit line for you. By default it is added under the exported figure (see [Exporting](12-export.md)).
- If you remove it from the picture, copy it from the **Attribution** dialog and put it in your figure legend or methods. **Add as text object** places it on the page instead.
- Icons you recolour from CC BY or CC BY-SA collections are credited as "modified", as their licences require, and so are the ones the icon library adapted from their originals.
- If a figure uses a share-alike (CC BY-SA) icon, the dialog warns you. Check what your journal and the licence allow before using one.
- Pictures you import are credited only if you type a credit for them in the Credit field of the Inspector's Image section.

The full list of sources and licences is in **Icon credits and licences**, at the foot of the Icons panel.

## Citing the sibling apps

PlasmidPop and BarelySig are separate projects with their own citation details. If your figure includes a plasmid map or graph made with them, cite them as well.
