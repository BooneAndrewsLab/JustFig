# Text

## Adding text

1. Choose the Text tool (key T).
2. **Click** on the page to start a line that grows as you type, or **drag** to set a width, in which case the text wraps at that width.
3. Type. The editing bar floats under the text.
4. Press **Escape** or choose **Done** to finish.

To change text later, double-click it, or select it and choose **Edit text** in the Inspector's Text section. If you finish with nothing typed, the empty text object is removed. The whole editing session is one undo step.

## Rich text

Select some characters in the editor and use the buttons on the bar, or the keys. With nothing selected, the setting applies to what you type next.

- **B**, bold: Ctrl+B
- **I**, italic: Ctrl+I
- **x₂**, subscript: Ctrl+=
- **x²**, superscript: Ctrl+Shift+=

Subscripts and superscripts are made for chemical formulae and units: H₂O, Ca²⁺, 10⁻⁶ M, mm². Type "Ca", switch superscript on, type "2+", switch it off again.

The bar also has a **Font** menu (Arimo is sans-serif, Tinos is serif, Cousine is monospaced) and a **Font size (pt)** field. They apply to the selected characters.

## Greek letters and symbols

The **Ω** button opens a picker of Greek letters and symbols: lower- and upper-case Greek (α β γ … Ω), and signs such as ±, ×, ≈, ≤, ≥, ∞, →, ⇌, ° and Å. Click one to insert it at the cursor. The picker stays open so you can insert several.

## The Text section of the Inspector

With a text object selected, the Inspector's Text section sets, for the whole object:

- **Font** and **Size (pt)**
- **Align**: Left, Centre or Right
- **Auto width**: on, the box grows to fit a line; off, text wraps inside the box width
- **Line height**
- **Colour**

## Fonts and exports

The three fonts are built into JustFig, so text looks the same on every computer. In an exported SVG or PDF the text stays real, searchable text. If you cannot rely on the fonts being installed where the file is opened, choose **Outline text** when exporting (see [Exporting](12-export.md)).
